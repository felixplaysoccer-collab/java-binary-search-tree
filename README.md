# Java Binary Search Tree Map

Java project developed for CS 351: Data Structures and Algorithms at the University of Wisconsin–Milwaukee.

## Project Overview

This project implements a generic key-value map using a binary search tree in Java.

## Features

- Binary search tree with parent pointers
- Insert, search, update, and remove key-value pairs
- Generic types and custom comparators
- Ordered iteration through tree entries
- Concurrent modification detection
- Internal checks for tree structure and consistency

Java, Eclipse IDE
